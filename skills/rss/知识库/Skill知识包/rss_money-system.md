# Ramit Sethi · 个人财务流程方法说明

## 适用问题

- 自动化
- 财务系统
- 账户

## 核心原则

- 自动化前先确认现金流和缓冲
- 不推荐未核实的具体金融产品

## 标准步骤

1. 绘制收入和账单日期
2. 列出账户用途与转移规则
3. 设置余额不足及异常处理
4. 确定每月检查清单

- 资金流程图
- 自动化规则草案
- 异常检查表
